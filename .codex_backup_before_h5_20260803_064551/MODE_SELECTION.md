# 比赛题目按键选择

本工程只烧录一个固件，不再通过修改宏、Clean、Build 来切换第二问和第三问。
Q1～Q4 使用 1 ms GPIO 电平轮询和 20 ms 软件去抖，不依赖按键 GPIO 中断。

## 按键分配

| 按键 | 引脚 | 功能 |
|---|---|---|
| Q1 | PA23 | 在第二问 H2 与第三问 H3 之间切换选择，不启动 |
| Q2 | PA21 | 停用（按键疑似损坏） |
| Q3 | PB18 | 启动 OLED 当前选中的题目；运行中作为该题的操作/重启键 |
| Q4 | PA17 | 预留 |

## 比赛操作

1. 上电或按硬件 RESET，OLED 显示题目选择菜单，默认光标在 H2。
2. 按 Q1 在 H2/H3 之间切换，屏幕的 `SELECT` 显示当前选择；Q1 此时不会启动电机。
3. 按 Q3 启动当前选中的题目。若选择 H3，程序会清空视觉串口旧数据，收到第一帧有效坐标后自动开始。
4. 题目启动后会锁定，防止运行中误按 Q1 切换控制程序。
5. 要换题时按硬件 RESET，回到菜单后重新选择。
6. Q3、Q4 目前只完成引脚和中断预留，不会启动电机。

题目运行期间统一使用 Q3 作为该题原有的启动、复位或重新开始按键。
